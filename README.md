# 霓虹突围 · 俯视角搜打撤

一个用**原生 HTML + CSS + JavaScript + Canvas 2D** 编写的俯视角「搜打撤」（Extraction Shooter）小游戏。
全部代码集中在单个 `game.html` 里，**双击即可游玩**，不依赖任何游戏引擎、框架或外部资源。

---

## 快速开始

### 方式一：直接双击（最简单）
双击 `game.html`，用任意现代浏览器（Chrome / Edge）打开即可。

### 方式二：本地服务（推荐，和自动化测试环境一致）
```powershell
cd e:\think3
python -m http.server 8123
```
然后浏览器访问：<http://localhost:8123/game.html>

## 玩法循环

1. **备货**：在开始界面点「仓库 / 装备与补给」
   - 购买子弹（30 发 / 45 币）、购买药品（50 币，使用回 30 血）
   - 设置**本局携带子弹数量**（上限 210 发，且不超过备用弹总量）
   - 把药品等物资「装入」**背包区**，即可带入战场
   - 撤离带出的物资可在仓库「出售」换成游戏币
2. **进图**：点击「进入战场」。携带的子弹与背包区物资随本局带入（阵亡则一并损失）
3. **搜刮**：地图随机刷新铜 / 银 / 金宝箱，靠近按 `F` 开箱；物资带**搜索动画**，品质越高搜索越久
4. **战斗**：地图中有人机 AI 巡逻，发现你会寻路追击并开枪；被击杀 = 撤离失败，本局物资全部丢失
5. **撤离**：走到绿色**撤离区**，停留 3 秒读条完成即撤离成功，背包物资存入仓库、剩余子弹返还弹池

## 核心特性

- **单文件交付**：`game.html` 内含全部 HTML / CSS / JS，无构建、无 CDN、无外部图片
- **迷宫地图**：递归回溯 + 环路编织生成连续迷宫墙体，保证全图连通、处处有通路（非随机散方块）
- **战斗系统**：弹匣 30 发、`R` 换弹、进图总弹上限 210 发、弹道碰撞与伤害、粒子与飘字反馈
- **人机 AI**：巡逻 → 视线判定 → 迷宫 BFS 寻路追击 → 开枪；失去视野后仍会追「最后看到的位置」数秒
- **宝箱与品质**：铜 / 银 / 金三档宝箱，白 / 蓝 / 紫 / 金 4 品质物品；宝箱品级越高越易出高级物资
- **搜索动画**：开箱物资以「转圈」占位卡片逐件浮现，品质越高转得越久
- **背包系统**：20 格上限、`Tab` 查看、物品可丢弃落地并在开箱弹窗/地面重新拾取
- **撤离与仓库**：撤离区 3 秒读条、`localStorage` 持久化仓库与游戏币、购买子弹/药品、可自定义携带弹药
- **视觉风格**：深色霓虹描边风（青 / 紫），含小地图、HUD、粒子特效

## 调参与扩展

所有可调参数集中在 `game.html` 的 `CONFIG` 对象里，便于平衡性调整：

| 配置 | 含义 |
| --- | --- |
| `weapon` | 弹匣容量、备弹上限、换弹时间、射速、伤害、弹速 |
| `ai` | 人机数量、血量、速度、视野/射程、伤害、开火间隔 |
| `chests` | 铜 / 银 / 金宝箱刷新数量 |
| `chestSpin` | 各品质开箱搜索动画时长（毫秒） |
| `maze` | 迷宫房间数与环路打通概率 |
| `extract` | 撤离区半径与停留读条时长 |
| `raidTime` | 单局时长（秒） |
| `buyAmmo` / `medkit` | 子弹、药品的价格与效果 |
| `bagSlots` / `loadoutSlots` | 背包与仓库背包区格数上限 |

存档键：`localStorage["neon_extraction_save_v1"]`（包含游戏币、备用弹、携带量、仓库物资、背包区物资、战绩）。

## 技术说明

- 渲染：单个 `<canvas>` 负责全部游戏画面；HUD 与弹窗使用 DOM 叠加层，便于交互与样式
- 循环：`requestAnimationFrame` 驱动，按帧间隔计算 `dt`，面板打开时暂停世界推进
- 碰撞：圆形实体 vs 轴对齐矩形，分轴移动实现「贴墙滑动」
- 寻路：迷宫网格上的 BFS，供人机 AI 绕墙追击 / 巡逻
